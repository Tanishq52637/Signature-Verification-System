# ✍️ SigVerify AI

An interactive machine learning-powered signature verification platform that demonstrates the complete biometric authentication pipeline, from image preprocessing and feature extraction to classification and evaluation.

Built using HTML, CSS, JavaScript, OpenCV concepts, and Random Forest classification principles.

## What's Inside

### Signature Verification
- Upload signature images for verification
- Demo genuine and forged signatures
- Confidence score visualization
- Genuine vs Forged classification

### OpenCV Processing Pipeline
- Grayscale Conversion
- Gaussian Blur
- Otsu Thresholding
- Morphological Operations
- Bounding Box Cropping
- Contour Detection
- Feature Vector Generation

### Machine Learning
- Random Forest Classification
- 10-Dimensional Feature Vector
- Accuracy, Precision, Recall & F1 Metrics
- Confusion Matrix Visualization

### Educational Dashboard
- Feature Extraction Explorer
- Model Performance Analysis
- Interactive Learning Modules
- End-to-End Verification Workflow
