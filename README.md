# ✍️ SigVerify AI

SigVerify AI is an interactive machine learning application that demonstrates how handwritten signatures can be analyzed and classified as genuine or forged using computer vision, feature extraction, and machine learning techniques. The platform visualizes the complete biometric authentication workflow, making complex machine learning concepts easier to understand.

## 🚀 Features

### Signature Verification

* Signature Upload
* Genuine vs Forged Classification
* Confidence Score Prediction

### Computer Vision Pipeline

* Image Preprocessing
* Grayscale Conversion
* Gaussian Blur
* Otsu Thresholding
* Morphological Operations
* Contour Detection

### Feature Engineering

* Aspect Ratio Analysis
* Pixel Density
* Stroke Width Analysis
* Hu Moments
* Texture Features
* Edge Density

### Machine Learning

* Random Forest Classification
* Model Evaluation
* Precision, Recall & F1 Analysis
* Confusion Matrix Visualization

### Interactive Learning Dashboard

* Processing Pipeline Visualization
* Feature Exploration
* Classification Workflow Walkthrough
